从本地工程启动、商城资产归档、节点图复用到团队技术文档沉淀，全部浓缩于一个客户端。

🚀

01. UE 工程管理中枢 (Project Hub)

自动扫描本机安装的各版本 Unreal Engine，深度解析 `.uproject` 与 `DefaultEngine.ini`（自动识别 DX12、Lumen、VSM、HWRT 光追与 Git/P4V/SVN 状态）。支持卡片悬停静默轮播、剧场巨幕预览、右键直接生成 `.sln` 及创建桌面快捷方式。

📦

02. UE 数字资产金库 (Asset Vault)

告别网盘与下载目录里认不出内容的 `.zip / .7z / .rar` 压缩包。拖入资产即可自动写入仅 0.5KB 的 `_vault_meta.json` 极速元数据存档，管理 `_PreviewMedia` 本地预览图库，并支持一键移动归整至统一资产盘符。

🕸️

03. BlueprintUE 蓝图与材质工坊

在 UE5 编辑器中按 `Ctrl + C` 复制任意蓝图或材质节点，直接粘贴至客户端即可全息渲染出带真实引脚配色的可视化拓扑图。内置防堆叠自动排版引擎，点击「一键复制节点代码」即可随时贴回任意 UE5 工程。

📘

04. 研发知识库 (R&D Knowledge Center)

内置 10 套工业级虚幻研发 Markdown 规范模板（涵盖 Lumen 调优、GAS 架构、PCG 生态、MRQ 渲染等）。支持粘贴 Notion 公开链接递归抓取全文块树，或直接导入 Word (`.docx`) 自动抽离高清插图转换为标准技术笔记。
